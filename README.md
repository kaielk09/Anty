# Purple Client

Mod do Minecraft Java Edition. Repozytorium na GitHubie pozostaje pod nazwą `Anty`, ale nazwa moda widoczna w grze to **Purple Client**.

## Założenia pierwszej wersji

- Własna kategoria `Purple Client` w `Options → Controls → Key Binds`.
- Domyślny skrót otwierający GUI: `Right Shift`.
- Możliwość zmiany skrótu w ustawieniach sterowania Minecrafta.
- Ustawienia moda dostępne bezpośrednio w grze.
- Docelowe loadery: Forge, NeoForge i Fabric; inne tylko wtedy, gdy da się je poprawnie obsłużyć.
- Docelowe wersje Minecrafta: od 1.21 wzwyż, w zakresie faktycznie wspieranym przez dany loader.

Na razie zakres funkcji ogranicza się do GUI, skrótu klawiszowego i ustawień. Kolejne funkcje nie są jeszcze zaplanowane.

## Status

Projekt jest na etapie przygotowania. Obsługa konkretnej wersji Minecrafta i loadera będzie potwierdzana po zbudowaniu i przetestowaniu moda.

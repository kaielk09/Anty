# Anty — Minecraft Mod Creator

Graficzny kreator szkieletów modów Minecraft Java Edition 1.21.1 (Fabric).

## Uruchomienie
Otwórz index.html w przeglądarce. Do eksportu ZIP potrzebne jest połączenie z internetem (JSZip z CDN).

## Funkcje
- ustawianie nazwy moda, Mod ID, pakietu Java i opisu
- generowanie projektu Fabric 1.21.1
- opcjonalny przykładowy item, blok i komenda testowa
- eksport ZIP w przeglądarce

## Budowanie wygenerowanego moda
Wymagane JDK 21 i Gradle. Uruchom gradle build w folderze projektu; wynikowy JAR powinien znaleźć się w build/libs. Przed użyciem należy zbudować i przetestować projekt.
